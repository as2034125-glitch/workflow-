# 廣告用字檢查

台灣《食品安全衛生管理法》第 28 條：食品標示、宣傳或廣告不得有不實、誇張、易生誤解或宣稱醫療效能之情事。以下針對本次影片逐條檢查。

## 不可使用

| 字詞 | 原因 |
|---|---|
| 減脂、瘦身、燃脂、體脂下降 | 醫療效能／減肥宣稱 |
| 抗氧化、抗老、延緩老化 | 保健功效宣稱，非查驗登記健康食品不得使用 |
| 增肌、修復肌肉 | 生理功能宣稱 |
| 促進代謝、改善體質 | 醫療效能 |
| 無糖、零糖 | 除非營養標示確認為 0 g，否則屬不實標示 |
| 100% 純可可 | **不實**。本品為豌豆蛋白飲，可可為風味 |
| 取代手搖、比手搖更健康 | 比較性功效宣稱，且貶抑他類商品。只能描述自身體感 |

## 官網現有但廣告不建議沿用

商品頁寫有「**下午茶的美容補給**」。「美容」在食品廣告屬功效性描述，容易被認定為易生誤解。影片改用情境描述，不碰功效。

商品頁寫「**完美取代高糖手搖飲**」。語意可用，但「完美」是誇大詞，且「取代」帶有療效替換的暗示。影片改為體感描述「冰冰的，跟手搖一樣」——只講飲用感受與溫度，不宣稱替代或優於手搖飲。

## 可以使用（有事實依據）

- 「每包 24 克蛋白質」— 商品頁明列，屬營養成分陳述
- 「全素」「無奶」「豌豆蛋白」— 成分事實
- 「微苦、不甜膩」— 風味描述
- 「冰水就沖得開」— 沖泡方式陳述，屬產品物性事實（需與包裝沖泡說明一致）
- 「冰冰的，跟手搖一樣」— 飲用溫度與口感的體感描述，非功效或替代宣稱
- 「一杯 55 元」— 12 入 NT$660 ÷ 12，屬價格事實
- 「嘴饞隨時來一杯」— 情境描述，不涉功效
- 「現貨免等待」— 供貨事實。2026-07-30 查證 12 入（SKU `VG00C2`）庫存 196 組，宣稱成立；庫存見底必須撤掉這句

## ⚠️ 落地頁本身有問題，比影片更急

影片文案已經避開所有地雷，但**廣告會被連帶審查落地頁**。商品頁 `pea-protein-dark-chocolate` 的商品描述目前寫著：

> 定位為「**下午茶的美容補給**」，能**完美取代高糖手搖飲**

這兩句正是本文件上方列為不建議使用的說法 ——「美容」屬功效性描述，「完美取代」既是誇大詞也帶替代宣稱。影片改乾淨了，落地頁沒改的話，Meta 審核照樣可能拒登，而且商品頁本身就有《食安法》第 28 條的風險。

**建議投放前先修商品描述**，例如改為：「香氣醇厚、微苦不甜膩的可可風味，每包含 24 克蛋白質，全素豌豆蛋白、不加奶。」

## 必帶警語

> 本產品含輔酵素 Q10，十五歲以下孩童、懷孕或哺乳期間婦女，及服用抗凝血藥品之病患不宜食用。

Q10 屬衛福部限量管理原料，警語為法定標示。廣告素材帶上可降低 Meta 審核拒登與被檢舉的風險。
