## 7. 法定警語與合規要求

### 7.1 MBTI 主題的特殊注意

MBTI 對照表的口味描述**只能用情境描述，不能暗示功效**：

| 可以 | 不可以 |
|---|---|
| 「享受自己的安靜時光」 | 「助眠、放鬆身心」 |
| 「重視獨處時的一杯好味道」 | 「療癒感、舒壓」 |
| 「快速進入工作狀態」 | 「提升專注力、增強體力」 |
| 「隨性活潑，跟著心情選」 | 「補充元氣、恢復活力」 |

### 7.2 各 MBTI 組合的警語需求

因為每個 MBTI 組合都固定 4 種口味，可以預先標好每個組合需要哪些警語：

**含 Q10（醇黑可可）的字母**：F
→ 所有 MBTI 中間有 F 的（xNFx / xSFx）都需要 Q10 警語

**含 GABA（黑芝麻 / 香蕉 / 開心果）的字母**：I / P / E
→ 所有 MBTI 都至少含 I 或 E 其中一個，所以**每一個 MBTI 組合都需要 GABA 警語**

結論：**所有 Reels 都必須帶 GABA 警語**。含 F 的 MBTI（INFP、ENFJ、ISFJ 等）額外需要 Q10 警語。

### 7.3 警語原文

**Q10**
> 本產品含輔酵素 Q10，十五歲以下孩童、懷孕或哺乳期間婦女，及服用抗凝血藥品之病患不宜食用。

**GABA**
> 本產品含有 GABA，使用本產品應避免同時飲酒或服用降血壓、鎮靜及癲癇等藥物；孕婦、授乳者、嬰幼兒，須諮詢醫師方可使用。

**呈現方式**：影片結尾字卡小字常駐至少 3 秒。品牌方提供現成的警語圖卡給 KOL 直接疊上。

### 7.4 禁止使用的字詞（需寫進合約）

| 禁止 | 原因 |
|---|---|
| 減脂、瘦身、燃脂 | 醫療效能宣稱 |
| 增肌、修復肌肉 | 生理功能宣稱 |
| 取代正餐、一餐只要這杯 | 營養宣稱 + 易生誤解 |
| 助眠、好睡、放鬆、療癒、舒壓 | 保健功效宣稱 |
| 抗氧化、排毒、促進代謝 | 醫療效能 |
| 無糖、零糖、零負擔 | 除非營養標示可證 |
| 100% 純可可、純抹茶 | 不實（本品為豌豆蛋白飲） |
| 提升專注力、增強體力、補充元氣 | 生理功能宣稱 |

### 7.5 可以使用的

- 蛋白質克數（標對口味）
- 「全素」「無乳糖」「豌豆蛋白」
- 添加成分名稱（GABA、Q10、MCT 等）—— 只講「有添加」，不講「有什麼用」
- 風味描述（順滑、不甜膩、微苦、有層次）
