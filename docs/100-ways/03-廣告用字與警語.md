# 廣告用字與警語｜100 種喝法

依據《食品安全衛生管理法》第 28 條：食品標示、宣傳或廣告不得有不實、誇張、易生誤解或宣稱醫療效能之情事。

既有的 `docs/04-廣告用字檢查.md` 是針對單支可可廣告寫的，仍然有效。本文件是 100 支影片規模下的補充 —— 支數多、口味多、還有 UGC 投稿，風險面比單支廣告大得多。

---

## 1. 法定警語（必帶，不可省略）

### 1.1 醇黑可可（含 Q10）

適用編號：`004` `012` `013` `026` `030` `032` `039` `042` `049` `054` `060` `062` `068` `072` `073` `077` `080` `081` `087`

> 本產品含輔酵素 Q10，十五歲以下孩童、懷孕或哺乳期間婦女，及服用抗凝血藥品之病患不宜食用。

### 1.2 香蕉牛奶、黑芝麻牛奶、開心果可可（含 GABA）

適用編號：`006` `008` `009` `019` `020` `022` `025` `029` `033` `038` `041` `045` `048` `057` `058` `064` `065` `067` `071` `075` `078` `085` `089` `091` `092` `094` `095` `097` `098` `100`

> 本產品含有 GABA，使用本產品應避免同時飲酒或服用降血壓、鎮靜及癲癇等藥物；孕婦、授乳者、嬰幼兒，須諮詢醫師方可使用。

此段文字取自 Shopify 商品頁，三個口味完全一致，**逐字照抄，不要改寫或縮短**。

### 1.3 呈現方式

- 影片：片尾 CTA 畫面小字常駐至少 3 秒，需落在安全區內（規格見 `docs/01-剪輯規格.md`）
- 貼文：文案結尾固定帶上，不要藏在留言
- 混口味的配方要按實際用到的口味判斷：`039`（抹茶＋可可）只需 Q10；`100`（香蕉＋芝麻）兩款都含 GABA，帶一次即可
- `011` 與 `018` 標示為「任一口味」，拍攝時實際選了哪一款，就跟著那款的警語走

`recipes.json` 的 `warnings` 欄位已標好每一支需要哪一則，剪輯時直接讀取，不要靠人工判斷。

## 2. 不可使用的字詞

沿用既有檢查表，並針對本企劃補充。

| 字詞 | 原因 |
|---|---|
| 減脂、瘦身、燃脂、體脂下降 | 醫療效能／減肥宣稱 |
| 抗氧化、抗老、延緩老化 | 保健功效宣稱 |
| 增肌、修復肌肉、練後修復 | 生理功能宣稱 |
| 促進代謝、改善體質、排毒 | 醫療效能 |
| 無糖、零糖、低卡、零負擔 | 除非營養標示可證，否則屬不實標示 |
| 助眠、好睡、放鬆神經、舒壓 | **本企劃新增風險**。S10 晚安系列最容易踩 |
| 取代正餐、一餐只要這杯 | 易生誤解，且涉及營養宣稱 |
| 100% 純可可、純抹茶 | 不實。本品為豌豆蛋白飲，可可與抹茶為風味 |
| 幫助消化、順暢 | 保健功效宣稱。輕盈纖果凍的文案不要挪用到蛋白飲 |

## 3. 高風險系列的改寫對照

### S10 晚安・零咖啡因

這系列最容易寫出功效宣稱。**只講時間與成分事實，不講身體反應。**

| 不要寫 | 改寫成 |
|---|---|
| 睡前喝一杯，一夜好眠 | 睡前那杯，不含咖啡因 |
| 含 GABA，幫助放鬆 | 特別添加 GABA |
| 晚上喝不會睡不著 | 香蕉牛奶、黑芝麻牛奶、綜合穀物為零咖啡因配方 |
| 舒緩一天的疲勞 | 一天的最後一杯 |

「零咖啡因」是可用的事實陳述 —— 品牌自己的「零咖啡因組」商品頁已明列香蕉牛奶、黑芝麻牛奶、綜合穀物三款。**但僅限這三款**，不可延伸到含可可、咖啡、茶的口味。

### S1 手搖店平替

「平替」本身沒問題，但比較性宣稱要留在事實層面。

| 不要寫 | 改寫成 |
|---|---|
| 完美取代高糖手搖飲 | 下午茶換這杯 |
| 比珍奶健康 | 一包 24.1 克蛋白質 |
| 喝手搖不如喝這個 | 珍奶的那個位置，換這杯 |

商品頁現有的「下午茶的美容補給」與「完美取代高糖手搖飲」兩句**都不要沿用到影片**：「美容」屬功效性描述，「完美」屬誇大詞。

### S7 / S8 用吃的系列

不要寫「取代正餐」「一碗就飽」。改成情境描述：「前一晚做好，早上直接吃」。

## 4. 可以使用的（有事實依據）

- 各口味的蛋白質克數 —— 商品頁明列，屬營養成分陳述。**要標對**：拿鐵 24g、紅茶 24.1g、可可 24g、穀物 24.6g、開心果 24g、抹茶 23g、香蕉 26.2g、芝麻 22g
- 「全素」「無乳糖」「豌豆蛋白」—— 成分事實
- 添加成分的名稱陳述（膳食纖維、牛磺酸、啤酒酵母、GABA、L-色胺酸、MCT、Q10、白腎豆、藤黃果、綜合酵素、24 種全穀粉）—— 只講「有添加」，不講「有什麼用」
- 風味描述（醇厚、微苦、不甜膩、順滑不沙感）
- 價格事實：一杯 55 元（12 入 660 元 ÷ 12）
- 「零咖啡因」—— 僅限香蕉牛奶、黑芝麻牛奶、綜合穀物

## 5. 食安責任（本企劃特有）

教人做東西吃，就要承擔食安揭露責任。以下配方在影片與貼文都要帶對應提醒：

| 情況 | 適用編號 | 提醒文字 |
|---|---|---|
| 加了新鮮水果／豆漿／優格 | S5 全系列、`008` `043` `059` `061` `062` `063` `064` `069` `094` | 建議當日飲用完畢 |
| 需冷藏定型的甜點 | `065` `069` `071` `075` `076` `077` `079` `080` | 冷藏保存，3 日內食用完畢 |
| 保溫瓶／外帶 | `090` | 泡好後建議 2 小時內飲用完畢 |
| 熱沖泡 | S9 全系列、`056` | 水溫勿超過 80°C |
| 氣泡飲 | `015` `054` | 請勿密封搖晃 |

## 6. UGC 階段的審核

開放投稿之後，用字風險從品牌轉移到消費者，但**法律責任仍在品牌** —— 官方帳號轉發＝品牌發布。

徵集辦法必須明文寫入：

1. 投稿內容不得出現本文件第 2 節的任何字詞
2. 投稿即授權 AGUGU 於社群管道使用（含剪輯與加字卡）
3. 品牌保留不選用的權利，且轉發前會重新加上必要警語
4. 涉及第 5 節情況的配方，品牌轉發時會補上食安提醒

**每一則轉發前逐則過第 2 節的清單。** 100 支影片有 30 支來自外部，這是整個企劃法規風險最高的一段。

## 7. 送審前的自檢流程

每支影片上稿前跑一次：

1. 字卡文案有沒有第 2 節的字詞？
2. 這支用的口味需要 Q10 或 GABA 警語嗎？（查 `recipes.json` 的 `warnings`）
3. 警語有沒有在片尾常駐滿 3 秒、有沒有超出安全區？
4. 蛋白質克數標的是這支實際用的口味嗎？
5. 需要食安提醒嗎？（查第 5 節）
6. 導購連結指向的規格有貨嗎？（醇黑可可一律指 12 入，1 入 SKU `VG00C1` 庫存為 0）

第 6 點看起來與法規無關，但導到缺貨頁面在 Meta 廣告政策下屬於「著陸頁體驗不佳」，會影響帳號評分。
